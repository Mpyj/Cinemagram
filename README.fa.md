# 🎬 سینماگرام | Cinemagram

> **یک پلتفرم فول‌استک مدرن برای فیلم، سریال و انیمه**

**سینماگرام** یک پلتفرم جامع سرگرمی برای جستجو، مدیریت و دانلود فیلم، سریال و انیمه است که به صورت Full-Stack توسعه داده شده.

این پروژه دارای سیستم احراز هویت، نقش‌ها و سطح دسترسی، مدیریت محتوا، مدیریت فصل و قسمت، نظرات، علاقه‌مندی‌ها، جستجوی پیشرفته، رابط کاربری ریسپانسیو و سیستم Import خودکار محتوا از APIها و فایل‌های مختلف است.

# 🚀 راه‌اندازی

## ۱. دریافت پروژه

```bash
git clone https://github.com/Mpyj/Cinemagram.git
cd Cinemagram
```

---

## ۲. راه‌اندازی Backend

```bash
cd backend

python -m venv venv
```

### ویندوز

```bash
venv\Scripts\activate
```

### نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### اجرای Backend

```bash
uvicorn app.main:app --reload
```

---

# 🗄️ راه‌اندازی دیتابیس

مطمئن شوید PostgreSQL نصب و فعال باشد.

وارد PostgreSQL شوید:

```bash
psql -U postgres -h localhost
```

سپس دیتابیس را ایجاد کنید:

```sql
CREATE DATABASE cinemagram;
```

و دیتای اولیه را وارد کنید:

```bash
python seed_data.py
```

---

# 🌐 راه‌اندازی Frontend

در یک ترمینال جدید:

```bash
cd frontend

npm install

npm run dev
```
